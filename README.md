# AI Medical Symptom Checker

A supervised machine learning web app that predicts diseases based on selected symptoms.

## Models Used
- Decision Tree
- Random Forest (deployed)
- Naive Bayes

## Dataset
Disease Symptom Prediction — Kaggle (itachi9604)
